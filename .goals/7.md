## Description
面板右侧状态列现在是「完成 5/5」这种写法，会折行，显得拥挤。改成英文，让项目更通用。每个目标只显示一个标签：没有进度时显示状态词（idea、done 等）；有进度时显示「当前 task / 总数」，3/3 表示正在做最后一个 task；最后一个 task 完成后，目标本身变成 done，不再显示 done 3/3。
## Acceptance
1. 面板和 /ms-status 中每个目标右侧只有一个标签：idea / planning / planned；执行中显示 k/n（k 为进行中或下一个 task）；完成显示 done；拆成子目标的父目标只显示状态词。右侧标签不折行。
2. 拆成 tasks 的目标，最后一个 task 结束（完成或跳过）后自动变为 done；/ms-done 只用于拆成子目标的父目标。
3. 用户可见的全部内容为英文：面板、命令说明与回复、toast、工具描述与回复、SKILL.md、README、目标文件的小节标题。读取时新旧（中文）标题都认，写入时用英文。
4. claude plugin test、validate、tsc 全过；真实环境验证通过。
## Approach
右侧标签由一个纯函数 labelOf(pool, goal) 算出，面板和 /ms-status 共用；面板右列不收缩、不折行，标题列截断。finish_task / skip 结束最后一个 task 时，在同一次写入里把目标设为 done，停 auto，照常给父目标提示。英文化：把字符串全部换成英文；SECTION 改英文标题，解析时把旧中文标题映射到英文，写入时只写英文。
## Decisions
先做 #7 再做 #6。拆成子目标的父目标不显示进度，进度看子目标。最后一个 task 是跳过而结束的，也自动 done（与原 /ms-done 的「全部 task 已结束」判定一致）。SKILL.md 要求完成最后一个 task 前先对照整个目标的验收标准自检。旧文件不批量迁移，下次写入时自然换成英文标题。
